# Prompt Master — Exposicions v9.0.2 Stable

Aplicació estàtica compatible amb GitHub Pages. Manté l’arquitectura modular de 8 fitxers.

## Novetats v9.0.2

- **Unified Exhibition State v1.0**: una única fitxa canònica alimenta prompt visual, dossier i exportació JSON.
- **Visual/Dossier Coherence Lock v1.0**: bloqueja coincidència de tipus d’obra, materials, escala, paleta, arquitectura, museografia i pràctica de l’artista fictici.
- El dossier deixa d’inventar materials o disciplines alienes a la imatge seleccionada.
- L’artista fictici adapta la seva disciplina i materials a l’exposició actual sense perdre nom, origen, any i base.
- Les metàfores automàtiques només apareixen si deriven d’evidències concretes; si no, el motor utilitza **Cap — llenguatge literal**.
- El Prompt Master incorpora un bloc **IDENTITAT DE L’EXPOSICIÓ** perquè la imatge generada comparteixi la mateixa idea central que el dossier.
- Manté el **Photographic Realism / Anti-Perfection Engine v1.0** de v9.0.1.
- Manté arquitectura recuperada, Site-Responsive Art Engine, selfie, CCTV, artistes reals de referència, presets i exportacions.

## Fitxers

`index.html`, `styles.css`, `data.js`, `engine.js`, `app.js`, `manifest.webmanifest`, `icon.svg`, `README.md`.

Per GitHub Pages, puja els vuit fitxers directament a l’arrel del repositori.
